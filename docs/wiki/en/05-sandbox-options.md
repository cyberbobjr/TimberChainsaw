# Sandbox options

[Home](Home.md) · Previous: [Felling trees](04-felling-trees.md) · Next: [Multiplayer](06-multiplayer.md) · [Français](../fr/05-sandbox-options.md)

The options are on the **Chainsaw B42** page of the sandbox settings. They keep the names of the original mod, so existing server settings still apply.

| Option | Default | Range | Effect |
|---|---|---|---|
| Fuel consumption | 100 % | 0–500 | 100 = a full tank lasts about 16 minutes idling at ×1, less while cutting. 0 = no consumption. |
| Damage | 100 % | 25–500 | Damage of a running Timber chainsaw, applied when it starts. |
| Combat wear | 12 | 0–100 | Condition lost per zombie killed with a running chainsaw (out of 127). 0 = none. |
| Tree cutting wear | 1 | 0–20 | Condition lost, one chance in 8 per cut. 0 = none. |
| Tree cutting speed | 100 % | 25–400 | 100 = a small tree in 1 to 3 s, the biggest in about 11 s (cut tree action). Also scales the tree damage of attacks on a tree (67 points per hit at 100 %). |
| Endurance cost | 50 % | 0–200 | Share of the endurance cost of a 7 kg weapon swung every 0.67 s. 0 = none. |
| Noise radius (idle) | 20 | 0–100 | Radius in tiles, every 2 s while the engine runs. 0 = silent. |
| Noise radius (attacking, cutting) | 40 | 0–100 | Radius in tiles, every 2 s while attacking or cutting. 0 = idle noise only. |
| Starting failures | 25 % | 0–100 | Chance that a chainsaw below half condition fails to start. 0 = never. |
| Chainsaw loot | 3 | 0–10 | 3 = default (1 to 3 % per roll). 0 = none. Applied when the game starts; the magazine is not affected. |

Note: with 127 condition points, the default **Combat wear** of 12 per kill breaks the chainsaw after about 10 zombies, plus the vanilla wear per hit.

> Capture à faire : the Chainsaw B42 sandbox page.

## Sounds

The chainsaw sounds follow the **Sound effects** slider. Each one can also be adjusted in **Options > Audio > Advanced**, category Weaponry.
